# Графическая часть RateFlow

[Комплект UML для ЛР5](lab5/README.md) содержит варианты использования, активность, состояния правила уведомления и последовательность конвертации. Форматы: Visio, PNG, SVG и PlantUML.

## Структуры интерфейса ЛР3

Схемы показывают определение страницы `part def`, составные части `part` и типы компонентов с атрибутами. Чёрный ромб обозначает композицию. Это структурные прототипы GUI, а не координаты элементов сайта.

| Экран | SysML v2 | PNG |
|---|---|---|
| Курсы валют | [Исходник](codes/rates-page.sysml) | [Схема](rates-page.png) |
| Конвертер | [Исходник](codes/converter-page.sysml) | [Схема](converter-page.png) |
| История курсов | [Исходник](codes/history-page.sysml) | [Схема](history-page.png) |
| Уведомления | [Исходник](codes/notifications-page.sysml) | [Схема](notifications-page.png) |

[Визуальные мокапы](mockups/README.md) показывают расположение элементов четырёх экранов. ЛР3 сохраняет исходный объём; изменения доступа и личных данных 0.3 описаны в ЛР5. Проверка исторических SysML-моделей специализированным компилятором в рамках ЛР5 не выполнялась.
