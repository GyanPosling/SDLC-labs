# BloodPressureMvcApp

Мобильное приложение на Kotlin для лабораторной работы: утилита информирует пользователя об идеальном артериальном давлении и оценивает текущее давление.

## Что реализовано

- Главная форма с кнопкой `Ввести данные`.
- Отдельное окно ввода без стандартного элемента выбора даты: дата рождения вводится тремя числовыми полями.
- Ввод веса, верхнего и нижнего текущего давления.
- Запоминание последнего успешного ввода на главной форме и восстановление этих данных при повторном открытии окна или перезапуске приложения.
- Расчет идеального давления по возрасту и весу.
- Оценка текущего давления: `повышенное`, `пониженное`, `норма`.
- Сообщение об ошибке при некорректных данных.
- Каркас MVC с активной моделью.

## MVC

- Model: `PressureModel`, `PressureState`, `PressureInput`, `PressureResult`.
- View: `MainActivity`, `InputDialogFragment`, XML-разметка экранов.
- Controller: `PressureController`.

Активная модель реализована через список слушателей в `PressureModel`: после изменения состояния модель сама уведомляет представление, а `MainActivity` перерисовывает главный экран.

## Формула

Идеальное давление рассчитывается по учебной формуле:

```text
верхнее = 109 + 0.5 * возраст + 0.1 * вес
нижнее = 63 + 0.1 * возраст + 0.15 * вес
```

Давление считается повышенным, если верхнее больше идеального более чем на 10 или нижнее больше идеального более чем на 7. Давление считается пониженным по тем же отклонениям вниз.
