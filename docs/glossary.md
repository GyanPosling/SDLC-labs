# Глоссарий RateFlow

Версия 0.3. Автор: Бурш Антон Павлович. Дата: 23.11.2026.

Термины применяются в [SRS](../srs.md), [SDD](../sdd/sdd.md), [сценариях](use-cases.md) и [ADR](../adr/adr.md). Область версии и отличие от плана версии 0.2 указаны в [описании динамического моделирования](dynamic-modeling.md).

| Термин | Определение |
|---|---|
| RateFlow | Информационное веб-приложение для просмотра официальных курсов, конвертации, анализа истории и уведомлений о скачках. Не выполняет реальный обмен денег. |
| НБРБ | Национальный банк Республики Беларусь; внешний поставщик официальных курсов и исторических данных. |
| Валюта | Поддерживаемая денежная единица: BYN, USD, EUR или RUB. |
| Базовая валюта | BYN, относительно которого задаются официальные курсы и рассчитываются изменения. |
| Валютная пара | Исходная и целевая валюты пересчёта, например USD → EUR. |
| Номинал | Количество единиц иностранной валюты, к которому относится опубликованное значение курса. |
| Нормализованный курс | Стоимость одной единицы валюты в BYN: опубликованный курс, делённый на номинал. Для BYN равен 1. |
| Дата действия курса | Календарная дата, к которой относится официальный курс. Отличается от времени загрузки. |
| Время загрузки | Момент получения данных приложением, записанный в UTC; не меняет дату действия курса. |
| Снимок курсов | Проверенный набор значений выбранных валют за одну дату с источником, номиналами и признаком актуальности. |
| Кеш | Последние корректные данные, доступные для повторного чтения без нового обращения к источнику. |
| stale | Отметка, что актуальность сохранённых курсов не удалось подтвердить. Дата исходных данных сохраняется. |
| Конвертация | Справочный пересчёт суммы между валютами с учётом номиналов и единой даты курсов. |
| Обмен валют местами | Перестановка исходной и целевой валют в форме конвертера. Это действие интерфейса, а не банковская операция. |
| История курсов | Последовательность доступных значений курса за выбранные 7, 30 или 90 календарных дней. |
| Предыдущий доступный курс | Корректное значение за ближайшую более раннюю доступную дату; не обязательно за предыдущий календарный день. |
| Правило уведомления | Принадлежащая пользователю настройка отслеживания валюты с порогом, состоянием и отметкой обработанной даты. |
| Порог | Минимальный модуль изменения курса в процентах, при котором формируется событие: 0,1–100%, шаг 0,1%; значение по умолчанию 2%. |
| Резкий скачок | Рост или снижение нормализованного курса, модуль процентного изменения которого достигает порога правила. |
| Уведомление | Событие внутри личного списка с валютой, датами, направлением и процентом изменения. Не подразумевает email или push. |
| Дубликат уведомления | Повторное событие по тому же правилу пользователя за уже обработанную дату курса. |
| Неаутентифицированный пользователь | Роль посетителя без действующей сессии; доступны публичные курсы, конвертер, графики и вход. |
| Аутентифицированный пользователь | Роль пользователя с действующей сессией; дополнительно доступны собственные правила и события. |
| Аутентификация | Проверка учётных данных и создание пользовательской сессии. Самостоятельная регистрация не входит в рассматриваемую модель. |
| Сессия | Серверная связь запроса с проверенной учётной записью; источник идентификатора владельца личных данных. |
| Владелец | Пользователь, которому принадлежит правило или событие. Идентификатор владельца определяется по сессии. |
| Actor / актёр | Внешняя по отношению к системе роль человека или сервиса, участвующая в варианте использования. |
| Use Case / прецедент | Сценарий достижения цели актёра с предусловиями, потоками событий и постусловиями. |
| include | Обязательное включение общего поведения; стрелка направлена к включаемому прецеденту. |
| extend | Необязательное дополнение основного сценария при заданном условии; стрелка направлена к расширяемому прецеденту. |
| Обобщение | Связь частного актёра или прецедента с общим; незакрашенный треугольник направлен к общему элементу. |
| Узел слияния | Ромб, объединяющий альтернативные потоки без ожидания выполнения всех ветвей. Не является синхронизацией параллельных действий. |
| Линия жизни | Представление участника взаимодействия во времени на диаграмме последовательности. |
| Полоса активации | Интервал выполнения операции участником взаимодействия. |
| API | Программный интерфейс обмена данными. API НБРБ скрыт за границей RateProvider/адаптера. |
| DTO | Передаваемая между компонентами структура данных без привязки к представлению интерфейса. |
| UML | Язык моделирования структуры и поведения систем; для моделирования поведения используются четыре поведенческие модели. |
| SRS | Спецификация требований: что должна делать система и как проверяется результат. |
| SDD | Описание проектирования: компоненты, взаимодействия, данные и алгоритмы выполнения требований. |
| ADR | Запись решения с контекстом, альтернативами, последствиями и способом проверки. |
| MVP | Минимальный согласованный объём выпуска. План 0.2 версии 0.2 и проектируемое расширение 0.3 различаются. |
