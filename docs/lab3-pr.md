# Лабораторная №3: требования к приложению «КурсПульс»

Подготовлена спецификация веб-приложения для просмотра официальных курсов валют, пересчёта сумм, просмотра истории и уведомлений о скачках. Указаны бизнес-цели, границы первой версии и проверяемые критерии приёмки.

Добавлены текстовая модель GUI на SysMLv2, её графическое представление в PNG, вопросы для интервью и ответы на контрольные вопросы.

Просьба заказчику проверить состав валют, источник данных, периоды истории, определение скачка и допустимость уведомлений только при открытом приложении. Замечания фиксируются в обсуждении с указанием ID требования; принятые изменения и причины отклонения отражаются в `docs/lab3.md`.

Проверка документации: ссылки на локальные файлы и соответствие графической модели исходнику проверяются перед коммитом. Проверки приложения запланированы, реализации пока нет. Интервью и согласование не считаются завершёнными до получения реальной обратной связи.
