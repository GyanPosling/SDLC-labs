# Графическая часть лабораторной №3

[currency-ui.sysml](currency-ui.sysml) — текстовая структурная модель GUI в нотации SysMLv2: определения частей описывают экраны, строковые атрибуты — элементы интерфейса, составная часть Application объединяет четыре экрана.

[currency-ui.png](currency-ui.png) — графическое представление этой модели: контейнер приложения и четыре вложенные части с атрибутами. Это структурный прототип, а не снимок работающего приложения и не детальный дизайн размещения кнопок.

PNG создаётся из текстового исходника скриптом [render-ui.ps1](render-ui.ps1), который извлекает определения экранов и их строковые атрибуты и рисует блоки средствами Windows System.Drawing. Скрипт отвечает за представление модели; полноценная семантическая проверка SysMLv2-компилятором не выполнялась. Текстовая нотация сверена с примерами определений частей и атрибутов OMG.

Для обновления изображения из корня репозитория в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File srs/diagrams/render-ui.ps1
```

После изменения модели нужно пересоздать PNG и проверить читаемость. Исходник и изображение включаются в один коммит. Скрипт предназначен только для документации и не реализует приложение.
