# RateFlow

Учебный проект Бурша Антона Павловича: курсы валют, конвертер, графики и уведомления о резких скачках.

Ветка `dynamic-modeling` создана для ЛР5 от обновлённой `system-requirements`. Документация 0.3 описывает вход и личные уведомления; история 0.2 и план ЛР4 сохранены. Реализация нового объёма и испытания пока не подтверждены.
