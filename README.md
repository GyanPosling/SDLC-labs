# RateFlow

Проект Бурша Антона Павловича: курсы валют, конвертер, графики и уведомления о резких скачках.

Ветка `dynamic-modeling` содержит модели динамического поведения системы и создана от `system-requirements`. Документация 0.3 описывает вход и личные уведомления; история 0.2 и план версии 0.2 сохранены. Реализация нового объёма и испытания пока не подтверждены.
